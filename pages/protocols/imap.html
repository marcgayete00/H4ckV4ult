IMAP (TCP/143, TCP/993) POP3 (TCP/110, TCP/995)

IMAP allows online management of emails directly on the server and supports folder structures.POP3, on the other hand, does not have the same functionality as IMAP, and it only provides listing, retrieving, and deleting emails as functions at the email server.

Enumeration

    Performing basic scan in order to detect data

    nmap 10.129.14.128 -sV -p110,143,993,995 -sC

    Connect to server

      POP3

      Connect to POP3 server

      nc 192.168.10.1 110

      Then provide credentials

      USER mike
PASS securepassword

      Retrieve messages

      LIST
retr 1

      IMAP
      nc 192.168.10.1 143

      Then privide credentials

      A1 LOGIN username password

      Then list mailboxes

      A1 LIST "" *

      POP3 secure
      openssl s_client -connect 192.168.10.1:995 -quiet

      Then provide credentials

      USER mike
PASS securepassword

      Retrieve messages

      LIST

      IMAP secure
      openssl s_client -connect 192.168.10.1:993 -quiet

      Then privide credentials

      A1 LOGIN username password

      Then list mailboxes

      A1 LIST "" *

    Bruteforcing

      POP3

        For the insecure connection:

        hydra -l USERNAME -P /path/to/passwords.txt -f 192.168.10.1 pop3 -V

        For the secure connection:

        hydra -S -v -l USERNAME -P /path/to/passwords.txt -s 995 -f 192.168.10.1 pop3 -V

      IMAP

        For the insecure connection:

        hydra -l USERNAME -P /path/to/passwords.txt -f  192.168.10.1 imap -V

        For the secure connection:

        hydra -S -v -l USERNAME -P /path/to/passwords.txt -s 993 -f  192.168.10.1 imap -V
