LimeSurvey

LimeSurvey is a free and open-source web-based survey tool that allows users to create and distribute online surveys

Default password

  • Admin user: admin
  • Default password: password

Exploitation

    In case you have access to LimeSurvey as an admin user you could be able to install a plugin and achieve remote command execution.

    To do so clone the following repository: Here

    And use the command

    python3 limesurvey_rce.py -t http://customers-survey.marketing.pg -u 'admin' -p 'password'
