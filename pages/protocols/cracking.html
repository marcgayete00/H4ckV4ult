Cracking passwords

Here you can find a cheatsheet for cracking some passwords. There will be uncommon things hard to remember...

John the reaper

    Specifying hash formats

      john hash.txt --format=afs

    John the ripper rules

      In order to create a rule for john the ripper we need to create a new file and type the following:

      [List.Rules:sshRules]
c $1 $3 $7 $!
c $1 $3 $7 $@
c $1 $3 $7 $#

      The first line is the name of the rule which we need to make reference later. The sintax of creating the rules is the same as hashcat

      Finally appened the content to the end of the file /etc/john/john.conf. You can use the following command 

      sudo sh -c 'cat ssh.rule >> /etc/john/john.conf'

      Now start cracking by using the command

      john --wordlist=ssh.passwords --rules=sshRules ssh.hash

Hashcat

    Hashcat rules

      In case you found that you are not able to crack certain password with default wordlist you can use rules which provide variations of password presents in wordlists

      hashcat -m 0 hash.txt /usr/share/wordlists/rockyou.txt -r /usr/share/hashcat/rules/best64.rule

      This can also be used in case you know the password contains certain word. For example mycompany. In that case you could save that word inside a file and apply hashcat rules over it

      hashcat -m 3200 hash base.txt -r /usr/share/hashcat/rules/best66.rule

    Creating custom wordlist

      After creating any wordlist please checkout the hashcat website where you can find all chars for creating the custom rules. Here

      1. Situate the key words in a txt file

      2. Create a custom rule, chars used can be

      $1 #Append the character 1 to the end of password candidate                       
c  #Make the first character uppercase                        
@1 #Deletes all instances of the character 1 from the password candidate

In case you would like to scape special chars you should play with $ for example supose we would like to append 1@3$5. The rule should be 
$1$@$3$$5

      3. Test custom rule

      hashcat -r test.rule --stdout /usr/share/wordlists/rockyou.txt

      4. Use custom rule.

      hashcat hash -m 0 /usr/share/wordlists/rockyou.txt -r test.rule --force

      5. You can also dump the new wordlist in a file and test it from there (optional)

    Hascat masks

      In case you know that password contains certain format like (4 digits or first uppercase and other ones no...) we can specified in hashcat by using -a flag

      Here goes the list of the symbols

      ?l = lower case letter
?u = upper case letter
?d = digit
?s = special character

      Place the hash into a file. In case you are hashing it just do

      echo -n "mysupersecurepassword" | md5sum

      Now crack the password. -a is the mode for bruteforcing then the ?1 are then number of chars that the password contains and finally the -1 is the character set to use. Previous explation of it

      hashcat -m 0 -a 3 hash.txt ?1?1?1?1?1?1?1?1 -1 ?l

Cewl

    In case you would like to find passwords based on the information of a company you could use cewl

    The following command is an example of how to scan a web for credentials (-d) depth of spider, (-m) min length of words

    cewl https://www.inlanefreight.com -d 4 -m 6 --lowercase -w inlane.wordlist
