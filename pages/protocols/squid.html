Squid Proxy (TCP/3128)

Squid is a caching proxy for the Web supporting HTTP, HTTPS, and FTP protocols. It can be used to scan internal ports and bypass access controls.

Enumeration

    More information about pentesting squid can be found here

    If you you attempt to query the Squid proxy using a browser and you see something similar to means that the proxy is not well configured

    The following error was encountered while trying to retrieve the URL: http://192.168.194.189/

Connection to 192.168.194.189 failed.

The system returned: (111) Connection refused

The remote host or network may be down. Please try the request again.

Your cache administrator is webmaster.

    In that case we may try to use the following tool to scan internal ports which we can not see with the previous nmap

    python spose.py --proxy http://10.10.11.131:3128 --target 10.10.11.131

    Once you identify the ports remember to change the proxy configuration in the firefox browser in order to access them
