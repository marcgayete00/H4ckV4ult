PDF

PDF (Portable Document Format) is a file format used to present and exchange documents reliably, independent of software, hardware, or operating system.

PDF password cracking

    In some ocassion you may find a PDF file which is password protected. In that case we can use pdf2john to extract the hash and crack it

    pdf2john.pl file.pdf > hash.txt

    Then we can use john to crack the hash

    john hash.txt --wordlist=/usr/share/wordlists/rockyou.txt
